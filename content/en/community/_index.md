## Join the developer mailing list

The mailing list `dev@openserverless.apache.org` is the **primary channel** of the
project. Announcements, design discussions, release votes and decisions all happen
there — at the Apache Software Foundation, if it did not happen on the mailing
list, it did not happen.

You do not need to be a committer to join. Anyone can subscribe, read and post.

### Subscribe

1. Send an empty email to
   [dev-subscribe@openserverless.apache.org](mailto:dev-subscribe@openserverless.apache.org).
   The subject and body are ignored, so you can leave them blank.
2. You will receive an automated confirmation request from
   `dev-help@openserverless.apache.org`. **Reply to it**, leaving the subject as
   it is — it carries a confirmation code. The body can be empty.
3. A welcome message confirms that you are subscribed.

If the confirmation request does not arrive within a few minutes, check your spam
folder.

### Post a message

Once subscribed, write to
[dev@openserverless.apache.org](mailto:dev@openserverless.apache.org).

A few conventions that make things easier for everyone:

- Send plain text rather than HTML, and avoid attachments — paste logs and code
  inline or link to a gist.
- Keep one topic per thread, and reply below the text you are quoting.
- Include your `ops -info` output and the version you are running when reporting a
  problem.

### Read the archives

Every message is public and permanently archived. You can browse and search the
whole history — and read it before subscribing — at
[lists.apache.org](https://lists.apache.org/list.html?dev@openserverless.apache.org).

### Unsubscribe

Send an empty email to
[dev-unsubscribe@openserverless.apache.org](mailto:dev-unsubscribe@openserverless.apache.org)
and reply to the confirmation request, exactly as when subscribing.

## Sources and issues

Development happens in the open on GitHub, in the
[apache/openserverless](https://github.com/apache/openserverless) repository and
the related component repositories.

Open an issue there to report a bug or request a feature, and send a pull request
to contribute a change. Larger changes are worth raising on the mailing list first,
so the discussion is visible to the whole community and archived with the project.

See the [contribution guidelines](/contribution-guidelines/) to get started.

## Chat on the ASF Slack

For quick questions and day to day conversation, join the **#openserverless**
channel on the Apache Software Foundation Slack:
[the-asf.slack.com/archives/C07B6K5R3F0](https://the-asf.slack.com/archives/C07B6K5R3F0).

If you do not have an ASF Slack account, you can self-invite at
[s.apache.org/slack-invite](https://s.apache.org/slack-invite) using any email
address.

Slack is convenient, but it is not the official record: anything that matters —
proposals, decisions, votes — belongs on the mailing list, where it is archived
and visible to everyone.
